## 원형 바구니와 사탕

### 문제 설명

$N$개의 빈 바구니가 원형을 그리고 있습니다. 각 바구니는 1번 바구니부터 $N$번 바구니까지 시계 방향으로 번호가 붙어 있습니다.

1번 바구니에서 출발하여, 총 $Q$개의 명령을 순서대로 실행하고자 합니다. 명령의 형식은 다음과 같이 두 정수 ($A_i, B_i$)로 주어집니다. 명령의 내용은 다음과 같습니다.

* $A_i$가 $1$이면, 시계 방향으로 이동하며 자기자신을 포함한 $B_i$개의 바구니에 사탕을 하나씩 추가합니다.


* $A_i$가 $-1$이면, 반시계 방향으로 이동하며 자기자신을 포함한 $B_i$개의 바구니에 사탕을 하나씩 추가합니다.



모든 명령을 수행한 후, 각 바구니에 들어있는 사탕의 개수 중 최댓값을 출력하는 프로그램을 작성하세요.

---

### 입력 형식

첫 줄에 정수 $N$이 주어진다.

그다음 줄에 정수 $Q$가 주어진다.

그다음 줄부터 $Q$개의 줄에 걸쳐, $Q$개의 명령에 대한 정보가 주어진다.

이 중 $i$번째 줄에는 두 정수 $A_i, B_i$가 공백으로 구분되어 차례대로 주어진다.

---

### 출력 형식

첫 줄에 각 바구니에 들어있는 사탕의 개수 중 최댓값을 출력합니다.

---

### 제한 조건

* $1 \le N \le 100$

* $1 \le Q \le 100$

* $A_i \in \{-1, 1\} \quad (1 \le i \le Q)$

* $1 \le B_i \le N \quad (1 \le i \le Q)$

* **Time Limit:** 3500 ms


* **Memory Limit:** 128 MiB



---

### 예제 입력 1

```text
5
2
1 3
-1 2

```

### 예제 출력 1

```text
2

```

### 예제 설명

* 첫 번째 명령(`1 3`)을 실행한 결과, **1, 2, 3번 바구니**에 사탕이 하나씩 담기고, **3번 바구니**로 이동합니다.


* 두 번째 명령(`-1 2`)을 실행한 결과, **3, 2번 바구니**에 사탕이 하나씩 담기고, **2번 바구니**로 이동합니다.


* 모든 명령을 수행한 후, 1, 2, 3, 4, 5번 바구니에는 사탕이 각각 **1개, 2개, 2개, 0개, 0개** 있습니다. 따라서, 이 중 최댓값인 **2**를 출력합니다.

## 📌 Code Review 📌

### 01. 정답 풀이
```javascript
const fs = require("fs");

function solve() {
    const input = fs.readFileSync(0).toString().trim().split(/\s+/);
    if (input.length === 0 || input[0] === "") return;

    const n = parseInt(input[0], 10);
    const q = parseInt(input[1], 10);

    const baskets = new Array(n + 1).fill(0);
    let current = 1; // 1번 바구니에서 출발

    let idx = 2;
    for (let i = 0; i < q; i++) {
        const a = parseInt(input[idx++], 10);
        const b = parseInt(input[idx++], 10);

        // 현재 위치를 포함하여 b개의 바구니에 사탕 추가
        for (let j = 0; j < b; j++) {
            baskets[current]++;
            
            // 마지막 바구니에 사탕을 넣은 후에는 이동하지 않고 해당 위치에 멈춤
            if (j === b - 1) break;

            if (a === 1) {
                // 시계 방향 이동 (1 -> 2 -> ... -> N -> 1)
                current = (current % n) + 1;
            } else if (a === -1) {
                // 반시계 방향 이동 (1 -> N -> N-1 -> ... -> 1)
                current = current === 1 ? n : current - 1;
            }
        }
    }

    // 가장 많은 사탕 개수 구하기
    let maxCandies = 0;
    for (let i = 1; i <= n; i++) {
        if (baskets[i] > maxCandies) {
            maxCandies = baskets[i];
        }
    }

    console.log(maxCandies);
}

solve();
```

### 02. AI 피드백
- **0-indexed 전환 활용하기**
  - 1번부터 $N$번 바구니를 $0$번부터 $N-1$번 바구니로 생각하면 원형 이동 연산이 훨씬 쉬워진다.
  - 시계 방향 1칸: `(current + 1) % N`
  - 반시계 방향 1칸: `(current - 1 + N) % N`

    이렇게 0부터 $N-1$로 계산한 뒤, 나중에 바구니 번호나 결과를 출력할 때만 처리하면 경계값 조건문(if)을 대폭 줄일 수 있어 구현 속도가 2배 이상 빨라진다.
- **문제 읽기 후 '제자리 멈춤' 체크**
  - "자기 자신을 포함해 $B_i$개"라는 문장을 보자마자 "총 $B_i$번 사탕을 넣고, 이동은 $B_i - 1$번만 수행한다"라는 규칙을 메모해 두고 코딩에 들어가는 습관을 들이면 디버깅 시간을 크게 줄일 수 있다.
